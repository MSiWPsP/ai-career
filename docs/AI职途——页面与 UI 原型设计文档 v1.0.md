# AI职途——大学生智能职业成长平台
## 页面与 UI 原型设计文档 v1.0

---

# 一、文档目标

本文档用于确定 AI职途 平台的整体页面结构、视觉风格、核心页面布局及主要交互方式。

目标：

1. 明确系统有哪些页面；
2. 明确每个页面展示哪些信息；
3. 明确页面之间如何跳转；
4. 明确哪些页面用于比赛演示；
5. 为 Vue3 + Element Plus 前端开发提供直接依据。

---

# 二、整体产品风格

系统定位：

> 面向大学生的 AI 职业成长与模拟面试平台。

整体视觉建议：

- 简洁
- 年轻
- 科技感
- 教育产品感
- 避免传统后台管理系统风格
- 避免页面全是表格

系统应该更像：

```text
AI产品
+
成长平台
+
个人Dashboard
```

而不是：

```text
学生信息管理系统
```

---

# 九十二、职业规划师多会话交互补充

职业规划师页面使用抽屉展示历史会话，避免常驻侧栏压缩主对话窗口。顶部提供“会话记录”“新建对话”“清空内容”；会话支持重命名、归档、恢复和删除。

页面不向普通用户展示内部 `conversationId`。聊天记录以服务端为准，前端只缓存当前会话标识和未发送草稿；流式回答失败时保留用户问题，并使用同一个客户端消息标识安全重试。

# 九十三、职业规划师上下文状态补充

职业规划师欢迎语应说明 AI 会在每次提问时参考最新职业画像、技能和当前规划。右侧“当前职业画像”卡片同步展示已记录技能数量，并明确列出本次对话可参考的数据；资料缺失时提示用户完善，不再显示“暂未自动读取”的旧状态。
