# 实习与校招准备清单

## 先明确目标与约束

明确目标岗位、城市、可到岗时间、每周可投入时间以及希望从实习中获得的能力。若目标仍不确定，可以从两三个相关方向出发，通过岗位描述、课程项目和小规模实践比较，而不是先给自己贴上固定标签。

## 准备可验证材料

简历应让招聘方快速看见与岗位相关的技能和证据。项目描述按“背景与目标—个人负责部分—关键做法—可核实结果”组织；没有测量过的性能提升、用户量或业务收益，不应编造数字。代码仓库、演示环境和测试说明要保持一致，且不要公开密钥或他人数据。

## 建立投递与复盘节奏

记录岗位要求、投递版本、反馈和下一步行动。投递后不必把每次没有回复都解释为能力不足；可按一段时间的反馈，判断是岗位匹配、材料表达、技术准备还是面试沟通需要调整。优先处理重复出现的问题，而不是同时重写所有材料。

## 面试准备

技术面试应练习解释设计依据、边界条件、失败处理和测试方法。对不熟悉的问题可以先澄清需求并说明推理过程，不要伪装熟悉。行为面试可准备协作、学习、解决冲突与复盘的真实案例。所有建议以目标公司实际流程和公开要求为准。
