# 大学生后端开发学习路线

## 阶段一：建立可运行的基础

先用 Java 编写小型程序，练习集合、异常、文件处理和单元测试，再用 SQL 完成增删改查和简单关联查询。每学一个知识点都保留可运行示例与简短复盘。若基础薄弱，优先补齐编程与数据库，不急于堆叠中间件。

## 阶段二：完成一个闭环服务

选择范围有限的真实问题，用 Spring Boot 构建 REST 接口，设计表结构，加入鉴权、参数校验、统一错误处理、迁移脚本和测试。先让核心业务闭环稳定运行，再逐步处理分页、并发、缓存或异步任务。每新增技术都应写清它解决了什么问题，以及不用它会有什么影响。

## 阶段三：补足工程化与故障定位

为项目添加构建、环境配置、日志和部署说明。用一次真实的慢查询或失败请求练习定位：描述症状，提出假设，收集证据，修改后复测。能解释性能瓶颈和数据一致性边界，通常比单纯背诵组件原理更能体现工程能力。

## 阶段四：面向求职整理证据

根据目标岗位筛选技能差距，完成一到两个有深度的项目案例，整理设计取舍、测试结果和个人贡献。用模拟面试检验表达，再根据反馈补缺。阶段所需时间取决于基础、可投入时间和目标岗位，不能把固定周数当作就业保证。
