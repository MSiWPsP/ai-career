# Java 后端岗位能力框架

## 语言与计算机基础

准备 Java 后端岗位时，先能解释并运用 Java 集合、异常处理、泛型、并发基础和常见 I/O 模式；同时理解数据结构、网络请求链路、操作系统的进程与线程等基础概念。学习重点不是记住术语，而是在具体问题中说明取舍，例如选择集合类型、处理并发写入或定位慢请求。

## 服务开发

应能使用 Spring Boot 完成接口、参数校验、业务分层、异常处理和测试。

## 数据库基础

数据库方面应理解 SQL、索引、事务与执行计划，并能说明数据模型如何支持业务查询。

## 缓存取舍

缓存是性能与一致性的工具，不应把 Redis 当作所有查询的默认答案；使用时需要考虑失效、更新和降级。

## 工程与交付

能够独立完成一个可运行服务，比罗列很多框架名更有证明力。项目应包含接口文档、自动化测试、日志、配置管理、数据库迁移与部署说明。能讲清楚一次请求如何从前端进入服务、经过鉴权和业务逻辑并落到数据库，以及出错时如何定位。

## Spring Boot 项目工程要素

一个用于展示后端能力的 Spring Boot 项目，至少应说明业务场景、接口契约、输入校验、鉴权与权限边界、分层职责、数据库迁移、异常响应、测试和环境配置。根据实际风险补充日志、超时、幂等与部署方式；不必为了简历强行加入所有中间件。能运行、能测试、能解释设计取舍，比依赖清单长更重要。

## 评估差距的方法

将目标岗位描述拆成“必须掌握”“入职后可学习”“特定业务才需要”三类，再拿实际项目证据逐项核对。不要仅凭技能自评分判断是否满足岗位要求；应结合代码、测试结果、性能排查记录和面试反馈。不同公司与岗位的侧重点不同，具体要求以目标岗位公开说明为准。
