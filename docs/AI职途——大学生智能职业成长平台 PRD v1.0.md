# AI职途——大学生智能职业成长平台
## 产品需求文档 PRD v1.0

### 一、项目基本信息

**项目名称：** AI职途——大学生智能职业成长平台  
**项目类型：** AI + 教育 + 职业规划智能体平台  
**目标用户：** 高校学生、应届毕业生、求职准备阶段学生  
**核心场景：** 职业规划、能力评估、学习路线制定、模拟面试、成长复盘  

---

# 二、项目背景

高校学生在职业发展过程中普遍存在以下问题：

1. 对职业方向缺乏清晰认识；
2. 不清楚自身能力与目标岗位之间的差距；
3. 网络学习资源较多，但缺乏针对个人情况的学习路线；
4. 缺少低成本、高频次、可复盘的模拟面试机会；
5. 学习、职业规划和面试训练之间相互独立，缺乏持续反馈机制。

传统职业规划通常依赖固定问卷、人工咨询或通用学习路线，难以根据学生个人技能水平、专业背景、职业目标以及成长过程进行持续调整。

因此，本项目计划构建一个基于人工智能智能体的大学生职业成长平台，通过职业规划智能体与模拟面试智能体协同，为学生提供个性化、动态化、持续迭代的职业发展服务。

---

# 三、项目目标

系统围绕大学生职业成长过程，建立：

**职业认知 → 能力分析 → 路线规划 → 学习实践 → 模拟面试 → 能力诊断 → 动态调整**

的完整闭环。

系统并非只提供普通 AI 问答，而是根据用户职业画像、历史面试表现和学习任务完成情况，为用户持续生成和调整职业发展方案。

# 四、核心产品理念

## 4.1 个性化

不同用户具有不同的：

- 专业背景
- 年级
- 已掌握技能
- 兴趣方向
- 学习时间
- 职业目标
- 求职阶段

AI 应基于具体用户画像进行分析，而不是输出完全相同的职业建议。

---

## 4.2 动态成长

职业规划不是一次生成后永久不变。

系统需要根据用户：

- 新掌握的技能
- 学习任务完成情况
- 模拟面试表现
- 职业目标变化

不断更新用户能力画像与职业规划。

---

## 4.3 多智能体协同

系统初期包含两个核心智能体：

### 1. 职业规划师 Agent

负责：

- 分析用户职业画像
- 推荐职业方向
- 分析能力差距
- 制定阶段性成长路线
- 根据用户成长情况动态调整职业规划

### 2. AI 模拟面试官 Agent

负责：

- 根据目标岗位开展模拟面试
- 根据回答质量动态追问
- 调整题目难度
- 分析用户知识掌握情况
- 生成面试能力报告
- 将面试结果反馈给职业规划系统

后期可扩展：

- AI 简历导师
- AI 学习导师
- AI 岗位推荐助手

# 六、用户核心痛点

## 痛点一：不知道自己适合什么职业

很多学生了解一些技术或专业知识，但不知道这些能力对应哪些职业岗位。

系统通过职业画像和 AI 分析，为用户提供职业方向建议。

---

## 痛点二：不知道自己离目标岗位还有多远

例如用户目标为：

> Java 后端开发工程师

系统分析：

- Java
- Spring Boot
- MySQL
- Redis
- JVM
- 计算机网络
- 数据结构
- 项目经验

等多个维度，形成能力差距分析。

---

## 痛点三：不知道下一步应该学什么

系统根据目标职业和当前能力状态生成分阶段学习路线。

例如：

### 第一阶段：基础强化

- Java 集合
- Java 并发
- JVM

### 第二阶段：中间件提升

- Redis
- RabbitMQ
- Elasticsearch

### 第三阶段：项目实践

- Spring Boot 项目
- 微服务项目
- 性能优化

---

## 痛点四：缺乏真实面试训练

传统面试题通常只是“刷题”。

本系统中的 AI 面试官会进行：

- 提问
- 分析回答
- 深入追问
- 调整难度
- 项目追问
- 综合评分

从而模拟更加真实的面试流程。

# 十三、动态面试机制

AI 面试官不能单纯按照固定题库逐题提问。

系统应根据用户回答动态进行下一步操作。

流程：

```text
AI提出问题
   ↓
用户回答
   ↓
AI分析回答质量
   ↓
┌───────────────┐
│ 回答较好       │ → 深入追问
│ 回答一般       │ → 引导追问
│ 回答错误       │ → 切换相关问题
└───────────────┘
```

例如：

AI：

> 请介绍一下 HashMap 的底层数据结构。

用户：

> JDK8 是数组、链表和红黑树。

AI 根据回答继续追问：

> 那么 HashMap 在什么情况下会将链表转换为红黑树？

从而形成真实的多轮面试体验。

# 十五、成长闭环

这是系统的核心功能之一。

面试结束后：

```text
面试报告
   ↓
提取能力变化
   ↓
更新能力画像
   ↓
职业规划 Agent 获取最新画像
   ↓
重新生成或调整成长任务
```

例如：

系统检测到：

> Redis 能力明显低于目标岗位要求

职业规划 Agent 可自动调整：

> 接下来两周将 Redis 缓存、分布式锁和缓存一致性加入重点学习任务。

从而实现：

**规划 → 学习 → 检验 → 调整**

的循环。

# 十七、Chat Memory

AI 职业规划师需要记住：

- 用户当前职业目标
- 用户之前咨询的问题
- 用户近期学习重点

AI 面试官需要记住：

- 已经问过的问题
- 用户之前的回答
- 当前面试上下文

从而保证多轮交互连续性。

---

# 十八、Tool Calling

Agent 可以调用后端业务能力。

计划提供：

```text
getUserProfile()
获取用户职业画像

getCareerPlan()
获取职业规划

getStudyTasks()
获取学习任务

getInterviewHistory()
获取历史面试结果

saveCareerPlan()
保存职业规划

updateUserAbility()
更新用户能力画像
```

通过 Tool Calling，使 Agent 不只是生成文本，同时能够操作系统业务数据。

# 二十三、项目核心创新点

## 创新点一：职业成长闭环

区别于普通职业问答系统，本系统实现：

> 职业规划 → 学习 → 模拟面试 → 能力诊断 → 规划调整

形成持续成长闭环。

---

## 创新点二：多 Agent 协同

职业规划师和模拟面试官分别承担不同任务，并共享用户成长数据。

---

## 创新点三：动态模拟面试

根据用户回答实时决定：

- 是否追问
- 追问方向
- 下一题难度
- 面试内容

提升真实面试体验。

---

## 创新点四：数据驱动职业规划

职业规划不只依赖用户主动输入，而是结合：

- 用户画像
- 学习记录
- 面试表现
- 能力评分

动态调整。

# 二十四、项目价值

本项目希望利用人工智能降低学生获取个性化职业规划和模拟面试指导的成本。

通过人工智能与高校职业教育场景结合，为学生提供更加持续、个性化和可执行的职业发展辅助工具。

最终形成：

> 一个懂用户、能规划、能面试、能诊断、还能持续调整成长路径的 AI 职业成长助手。
