# 智职星浅色成长首页改版说明

2026-10-03：依据用户提供的成长首页参考图，替换深蓝科技风。原功能、API 和数据库约定不变。

## 视觉与布局

- 浅蓝紫背景、白色圆角卡片、深色正文、蓝紫强调色；共享变量集中在前端 theme.css。
- 保留智职星现有品牌标识，采用白色侧栏和紧凑顶部栏。职业规划新增独立菜单入口，避免与规划师聊天同时高亮。
- 首页依次展示问候、目标岗位与定位/规划/执行/反馈流程、下一步行动、成长待办。
- 下方使用双列卡片：当前行动计划、能力提升重点、面试复盘、职业成长路线、方向探索、成长准备清单。
- 桌面双列，手机单列；沿用加载遮罩、空状态和减少动态效果设置。
- 画像、规划、任务、聊天、能力、面试及登录页面统一浅色背景与蓝紫强调色。

## 数据与功能边界

首页使用现有用户、画像、当前规划、任务、任务统计、能力雷达及最近面试接口。下一步优先显示进行中任务，其次待开始任务；没有任务时依照画像、规划和任务状态提供可操作入口。

参考图中的“本周投入时长”“目标能力分数”“项目成果验收”“作品集”没有对应业务数据，本轮没有伪造，也没有新增平行业务。分别使用当前任务统计、真实能力评分和职业成长路线组织相应位置。顶部未添加不可用的全局搜索框。

任务“开始”和“标记完成”使用已有状态更新接口；报告按钮仅在已完成面试时进入报告。成长清单表示已有画像/规划/完成任务/已完成最近面试的记录，不表示求职能力达标或审核通过。单个接口失败时保留其他区域并显示提示与重新加载入口。

## 验收

- npm run build：TypeScript 检查与生产打包。
- 使用 Playwright 浏览器和临时模拟 API 验证有数据、空数据、接口失败及任务状态更新。
- 检查主要路由在桌面和手机宽度下的显示与 JavaScript 错误。
- 演示数据、临时登录信息及截图只用于本机验收，不提交、不写入后端或线上数据库。

本轮不修改后端接口、不操作服务器、不自动发布。上线时更新 Web 镜像即可，后端与数据库无需迁移。
