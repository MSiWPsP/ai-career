# 智职星深蓝科技风改版

> 历史方案：用户已选择浅色蓝紫参考图风格，本文件仅保留设计记录，不再作为当前视觉依据。现行方案见 [浅色成长首页改版说明](浅色成长首页改版说明.md)。

2026-10-03：根据用户最新确认，以深蓝科技风替代此前蓝白视觉方向。旧 UI 文档中的功能结构继续有效，本文件仅更新视觉约定。

## 设计边界

- 沿用 Vue、Element Plus、ECharts 和现有布局、路由及数据接口。
- 不引入等级、经验、徽章或游戏地图。首页突出职业目标、下一步行动、任务进度和能力反馈。
- 正式页面使用真实 API 数据；演示数据仅由本地浏览器验收临时拦截提供，不进入产品代码。

## 主题约定

页面背景 `#080f1f`，卡片 `#111e32`，次级背景 `#15243b`，主文字 `#e7eefb`，次级文字 `#a0b1ca`，强调蓝 `#63b3ff`。集中维护于 `src/styles/theme.css`，页面使用现有 CSS 变量。

主目标卡片使用低饱和深蓝渐变和局部青蓝光晕。其余卡片以细边框和留白组织信息；移除首页大面积圆环和点阵装饰，缩短成长路线的占用高度。沿用短时页面过渡、悬停和真实加载反馈，并尊重减少动态效果设置。

Element Plus 的表单、选择器、菜单、对话框、抽屉、表格和加载遮罩使用同一组深色 Token。Canvas 图表通过 `getChartTheme()` 读取 CSS 变量，保证轴标签、网格和提示层在深色背景上可读。

## 验收方式

执行 `npm run build`；用浏览器检查首页、职业画像、职业规划师、规划、任务、面试配置与记录的桌面及移动端布局。截图、临时登录状态和模拟 API 数据仅用于本地检查，不提交。

本次改版不修改后端接口或数据库，不在代码中加入服务端凭证。线上部署需单独更新 Web 镜像。
