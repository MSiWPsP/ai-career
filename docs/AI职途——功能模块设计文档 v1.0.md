# AI职途——大学生智能职业成长平台
## 功能模块设计文档 v1.0

---

# 一、文档说明

本文档基于《AI职途——大学生智能职业成长平台 PRD v1.0》进行进一步功能拆分。

本阶段目标是明确：

- 系统由哪些功能模块组成
- 每个模块负责什么
- 模块之间如何协作
- 哪些模块属于传统业务系统
- 哪些模块属于 AI Agent 能力
- 后续如何映射到前端页面、后端接口、数据库表和 Agent Tool

系统整体围绕：

> 职业画像 → 职业规划 → 学习任务 → 模拟面试 → 能力分析 → 动态调整

构建完整的大学生职业成长闭环。

---

# 二十一、模拟面试过程

整体流程：

```text
开始面试
   ↓
AI提出问题
   ↓
用户回答
   ↓
AI分析用户回答
   ↓
判断回答质量
   ↓
决定下一步动作
   ↓
继续追问 / 切换问题
   ↓
完成面试
```

---

# 二十二、动态追问机制

这是 InterviewerAgent 的核心。

例如：

AI：

```text
请介绍一下HashMap底层结构。
```

用户：

```text
JDK8里面主要是数组、链表和红黑树。
```

AI 判断：

```text
基础回答正确
```

然后进入深入追问：

```text
链表在什么情况下转换为红黑树？
```

用户继续回答。

Agent 再判断：

```text
掌握较好
```

然后提升难度。

这样形成：

```text
回答优秀
→ 深挖

回答一般
→ 引导

回答较差
→ 降低难度 / 换题
```
