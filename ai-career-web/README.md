# AI职途前端

“AI职途——大学生智能职业成长平台”的 Vue 3 前端。项目使用 TypeScript、Vite、Element Plus、Pinia、Axios 和 ECharts，并与仓库中的 Spring Boot 服务共同完成“职业画像 → 职业规划 → 成长任务 → 模拟面试 → 能力诊断 → 动态重新规划”的业务闭环。

## 已实现功能

- 用户注册、登录、JWT 登录态和个人资料维护
- 阿里云 OSS 头像上传、替换与移除
- 职业画像、技能自评和资料完整度检查
- AI 职业规划师普通聊天、SSE 流式聊天和会话管理
- 结构化职业规划生成、历史版本查看和面试后重新规划
- 成长任务列表、筛选、统计和状态更新
- AI 模拟面试配置、动态问答、主动/自动结束和异常恢复
- 面试历史、结构化报告、报告失败重试和重新规划入口
- 能力雷达、能力趋势和评分历史
- 首页职业目标、规划路线、任务、能力和最近面试概览
- 基于真实画像和任务状态生成的通知菜单

AI 接口已经接入后端。职业规划、模拟面试和面试报告会调用配置的大模型服务，不使用伪造业务结果。结构化结果会由后端校验后持久化，完整接口契约以仓库 `docs` 目录为准。

## 本地运行

环境要求：Node.js 20+、npm，以及已启动在 `http://localhost:8080` 的后端服务。后端还需要 Java 21、MySQL 8 和可用的模型配置。

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。开发服务器会把 `/api` 请求代理到本地后端。

如需连接其他后端地址，复制 `.env.example` 为 `.env.local` 并修改：

```env
VITE_API_BASE_URL=/api
```

## 核心验收路径

1. 注册或登录账号。
2. 完善职业画像并保存技能自评。
3. 生成首版职业规划，查看成长路线和任务。
4. 配置并完成一次模拟面试，生成面试报告。
5. 查看能力雷达与趋势，并从报告触发重新规划。

进入 AI 职业规划师页面时默认展示新对话；历史会话需要从会话记录中主动打开。规划生成与报告生成依赖模型结构化输出，失败时页面会保留当前数据并提供可重试入口。

## OSS 头像上传

后端使用 `aliyun.oss` 中配置的上海地域 Endpoint 与 Bucket。启动后端前，需要设置具备对应 Bucket 读写权限的环境变量：

```text
OSS_ACCESS_KEY_ID
OSS_ACCESS_KEY_SECRET
```

头像支持 JPG、PNG、WebP 和 GIF，单个文件最大 5MB。替换或移除头像时，系统会回收属于当前 Bucket 的旧头像文件。

## 构建检查

```bash
npm run build
```

该命令会先执行 Vue/TypeScript 类型检查，再生成生产构建到 `dist`。

后端业务改动还应在 `ai-career-server` 目录运行：

```bash
mvn clean test
```
